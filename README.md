# מעבדת α7C II

קורס וסימולטור בעברית ללימוד צילום עם Sony α7C II ועדשת FE 24-50mm F2.8 G.

- `app/`: האתר (סטטי, ES modules, בלי build). פותחים עם `python3 tools/dev/serve.py` ונכנסים ל-http://127.0.0.1:8765
- `app/js/course/`: תוכן הקורס (11 פרקים)
- `app/js/engine.js`: רינדור פיזיקלי ב-WebGL2 (HDR, עומק שדה לפי עומק מטרי, רעש חיישן, רעידה ותנועה)
- `app/scenes/`: 7 סצנות (תמונה + מפת עומק + מטא-דאטה), שתי רזולוציות
- `tools/`: כלי הכנת סצנות (Depth Pro, חיתוך HDRI, הסרת רקע)
- `docs/SPEC.md`: חוזה התוכן והמבנה

קרדיטים לתמונות: בעמוד "מקורות וקרדיטים" באתר ובקובצי `scene.json`.
